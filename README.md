# Team SHD Bot - Railway

الكود الأساسي موجود في `main.py` واحد، مع ملفات إعداد بسيطة لـ GitHub وRailway.

Environment Variables المطلوبة:
- `BOT_TOKEN`
- `FOUNDER_ID`
- `DB_PATH` اختياري، والأفضل على Railway استخدام Volume مثل `/data/bot.db`

Start Command:
`python main.py`

SQLite تُنشأ تلقائيًا عند التشغيل.
